Bouton 1

Sans titre

Apparence

Action

Connecter OBS Studio

À faire une seule fois, ça prend 2 minutes. L'app se reconnecte ensuite toute seule à chaque lancement d'OBS.

Configuration d'OBS

  1. Vérifie ta version d'OBS

    Le serveur WebSocket est intégré à OBS depuis la version 28. Regarde ta version dans Aide → À propos. Si elle est plus ancienne, installe la dernière depuis obsproject.com.

  2. Active le serveur WebSocket

    Dans OBS, ouvre Outils → Paramètres du serveur WebSocket, puis coche Activer le serveur WebSocket. Laisse le port sur 4455.

  3. Copie le mot de passe

    Si Activer l'authentification est coché (recommandé), clique sur Afficher les informations de connexion puis sur Copier à côté du mot de passe du serveur.

  4. Colle-le ici et connecte-toi

    Colle le mot de passe dans le champ ci-dessus et clique sur Se connecter. Quand la pastille passe au vert, c'est bon : les noms de tes scènes et sources apparaîtront dans les listes de l'onglet Boutons.

Créer un bouton « animation »

  1. Ajoute la vidéo dans OBS

    Dans ta scène, clique sur + → Source média et choisis ta vidéo (idéalement un .webm avec fond transparent). Coche Redémarrer la lecture quand la source devient active et laisse Boucle décoché.

  2. Masque la source

    Clique sur l'icône en forme d'œil à côté de la source pour la cacher. C'est le bouton qui la fera apparaître.

  3. Configure le bouton

    Dans l'onglet Boutons, choisis l'action Source / animation, sélectionne ta source, garde le comportement Animation et règle la durée sur celle de ta vidéo. La source s'affiche, se joue, puis se masque toute seule.

Ça ne marche pas ?

La pastille reste grise « OBS hors ligne »

Vérifie qu'OBS est bien ouvert et que le serveur WebSocket est activé (étape 2). L'adresse doit être ws://127.0.0.1:4455 si OBS tourne sur ce PC.

« Authentication failed » / mot de passe refusé

Recopie le mot de passe depuis Afficher les informations de connexion. Si tu as cliqué sur « Générer un mot de passe » dans OBS, l'ancien ne marche plus : il faut coller le nouveau ici.

OBS tourne sur un autre PC

Remplace 127.0.0.1 par l'adresse IP affichée dans les informations de connexion d'OBS, et autorise OBS dans le pare-feu Windows de l'autre PC.

Le bouton ne change pas de scène

Le nom doit correspondre exactement (majuscules, espaces, accents). Une fois connecté, choisis la scène dans la liste proposée plutôt que de la taper.

Réglages

Raccourci d'ouverture

Clique puis appuie sur ta combinaison. Les touches F13 à F24 (souris ou claviers programmables) marchent aussi seules.

Fermer le deck après une action

Sinon il reste ouvert jusqu'à Échap ou un clic à côté.

Lancer au démarrage de Windows

L'app démarre discrètement dans la zone de notification.
